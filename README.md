# NERSI Enlightenment Guide

Independent informational website about Nigeria's National Emergency Relief and Stabilisation Intervention (NERSI) ₦50,000 cash support programme.

**Purpose:** Help people understand the official facts and avoid scam websites.

**Official source:** [https://fmhapr.gov.ng/nersi](https://fmhapr.gov.ng/nersi)  
**Helpline:** 0700-022-2222

This site is **not** affiliated with the Federal Government of Nigeria or the Federal Ministry of Humanitarian Affairs and Poverty Reduction.

## Deploy to Netlify

1. Go to [https://app.netlify.com](https://app.netlify.com)
2. Click **Add new site** → **Import an existing project**
3. Connect your GitHub account and select this repository (`nersi-enlightenment`)
4. Deploy settings can stay as default (it will detect the `index.html`)
5. Click **Deploy site**

Your site will be live in under a minute on a free Netlify subdomain (you can later add a custom domain).
